# Code and data for Figure 1

Code and data supporting the bioinformatics analyses in Ha et al.

## Contents

- `data/` — essential data used or generated by the bioinformatics analyses supporting
  Fig. 1a–d, Supplementary Fig. 1, Tables S4–S5, and Supplemental Note 1.
  See `data/README.md` for file-by-file documentation.
- `data/transposase-counts.csv` — per-replicon transposase-related annotation counts
  (63,425 replicons; analysis input from R. Maddamsetti,
  github.com/rohanmaddamsetti/darwinian-circuit).
- `data/PIRA-PCN-estimates.csv` — published pseuPIRA plasmid copy-number estimates
  (16,861 rows), from the Supplementary Information of Maddamsetti et al.,
  *Nature Communications* 16:6023 (2025), DOI 10.1038/s41467-025-61205-2
  (file `41467_2025_61205_MOESM3_ESM.csv`, downloaded 2026-08-31).
  The same two source tables also appear in gzipped form as `1_*.csv.gz`.
- `code/fig1a.py` — regenerates Fig. 1a from `transposase-counts.csv`.
- `code/fig1b.py` — regenerates Fig. 1b from the two public source tables above.
- `code/fig1d.py` — regenerates Fig. 1d from `data/7_Enrichment_table.csv`.
- `code/pipeline/` — reference copy of the full sequence-level analysis pipeline,
  including scripts 01–16, SLURM jobs, and conda environments. The pipeline
  generated the result tables in `data/`; see `code/pipeline/README.md`.
  These scripts assume the original project layout, configurable through
  `NEE_PROJECT_ROOT` and `NEE_RESULTS_DIR`, and are provided for provenance.
  The standalone scripts above are the simplest way to regenerate the displayed
  Fig. 1 panels from this repository.

## How to run

```bash
cd code
python3 fig1a.py
python3 fig1b.py
python3 fig1d.py
```

The standalone plotting scripts require Python 3 and matplotlib. They write
vector PDFs with editable TrueType text and 300-dpi PNGs next to the scripts.

## Expected results

- Fig. 1a transposase-related annotation densities:
  53.2 annotations/Mbp for plasmids and 10.6 annotations/Mbp for chromosomes.
- Fig. 1b fractions of plasmids with at least one transposase-related annotation:
  1923/2322 = 82.8%, 4198/6396 = 65.6%, 166/2124 = 7.8%, and
  6/166 = 3.6% for PCN bins <1, 1–10, 10–100, and 100–1000, respectively.
  A total of 11,010 plasmids have coverage-based PCN estimates that join to the
  annotation table; 2 with PCN >= 1000 fall outside the four displayed bins.
- Fig. 1c sequence-context analysis:
  9,244/25,801 = 35.8% of exact-sequence-deduplicated plasmids contain an
  identical same-family IS-copy group in at least two distinct exact 10-bp
  outer-flank contexts.
- Fig. 1d qualifying functional annotations among putative cargo versus background
  protein instances:
  7.29% vs 0.52% (CARD), 2.70% vs 0.80% (VFDB Set B),
  2.25% vs 1.30% (BacMet2 EXP), and 2.44% vs 0.94% (TADB2).

## Sequence-level analysis

The full pipeline performs the sequence-level analyses summarized in Fig. 1c–d
and Supplementary Fig. 1.

- IS elements were annotated with ISEScan v1.7.3.
- Exact duplicate plasmid nucleotide sequences were removed before the
  sequence-context analysis.
- Identical same-family IS copies were compared using exact 10-bp sequences
  immediately outside both IS boundaries after orientation normalization.
- Under the primary cargo definition, coding sequences within spans of no more
  than 25 kb between two same-family IS copies were treated as putative cargo;
  non-IS-overlapping proteins on the same IS-carrying plasmids formed the
  background set.
- Cargo and background proteins were searched with DIAMOND v2.2.1 blastp using
  `--very-sensitive`, an E-value threshold of `1e-10`, and the best hit only.
  Searches used CARD, VFDB Set B, BacMet2 EXP, and TADB2.
- The primary functional-annotation filter required >=90% amino-acid identity
  and >=60% query coverage. A sensitivity analysis used >=80% identity and
  >=70% query coverage.
- Enrichment was tested with two-sided Fisher exact tests followed by
  Benjamini-Hochberg correction across the four primary database comparisons.
  AMRFinderPlus provided an independent antibiotic-resistance sensitivity check.

Full definitions, intermediate counts, sensitivity analyses, and the mapping
between result files and manuscript claims are documented in `data/README.md`,
Supplemental Note 1, and Tables S4–S5.

## Scope

The standalone `code/` scripts regenerate Fig. 1a, Fig. 1b, and Fig. 1d
directly from the included data. Fig. 1c is a schematic/summary panel rather
than a standalone script-generated plot; its reported 9,244/25,801 result comes
from `data/10_Summary.txt`, with per-plasmid records in
`data/10_Per_plasmid.csv`.
