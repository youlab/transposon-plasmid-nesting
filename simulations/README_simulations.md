# Simulations

Jupyter notebooks for the manuscript's main, Extended Data, and Supplementary simulation figures.

All figure notebooks use `simulation_core.ipynb` in the same directory.

| Notebook | Content |
|---|---|
| `simulation_core.ipynb` | Shared TCN-state model, growth and redistribution functions, serial-passage simulations, convergence checks, and supporting utilities. |
| `Figure_2.ipynb` | Figure 2d–g: TCN-dependent growth functions and TCN trajectories under fixed and fluctuating selection. |
| `Figure_5.ipynb` | Figure 5a: TCN loss and gain rates across maximum PCN capacities. |
| `Extended_Data_Figure_2.ipynb` | Extended Data Figure 2: sensitivity to joint scaling of forward and backward redistribution coefficients. |
| `Extended_Data_Figure_3.ipynb` | Extended Data Figure 3: effects of redistribution turnover and directional bias on TCN gain rates. |
| `Extended_Data_Figure_4.ipynb` | Extended Data Figure 4: sensitivity to chromosomal lower-boundary assumptions. |
| `SF_2.ipynb` | Supplementary Figure 2: sensitivity to the transposition-associated forward-rate increment. |
| `SF_3.ipynb` | Supplementary Figure 3: sensitivity to PCN-dynamics transition increments. |
| `SF_4.ipynb` | Supplementary Figure 4: sensitivity to removal of the persistent chromosomal transposon copy. |
| `SF_9.ipynb` | Supplementary Figure 9: sensitivity to normal-distribution initialization. |
| `SF_10.ipynb` | Supplementary Figure 10: sensitivity to uniform and random initialization. |
| `SF_11.ipynb` | Supplementary Figure 11: sensitivity to alternative TCN-dependent growth profiles. |
| `SF_12.ipynb` | Supplementary Figure 12: sensitivity to coupling between transposition status and maximum PCN capacity. |
