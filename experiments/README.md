# Experimental data and figure-generation workflow

This folder contains the experimental data, processed tables, and plotting notebook used for the experimental analyses in Ha et al.

The package supports the experimental panels in **Figures 3, 4, and 5b** and the associated supplementary analyses.

## Main analysis notebook

`Fig3_Fig4_Fig5_SuppFig7_8_plotting_code.ipynb`

This notebook contains the qPCR, GFP/OD600, response-rate, growth-curve, and Figure 5b plotting workflow. Run it from the `experiments/` directory and execute each analysis section from top to bottom because later sections use dataframes and processed files created earlier in the notebook.

The notebook uses Python 3 with packages including:

- numpy
- pandas
- scipy
- matplotlib
- seaborn
- altair
- statannotations
- marimo
- Excel readers required by pandas for `.xls` and `.xlsx` files

## Experimental design represented in the package

The long-term experiments follow three cycles of:

- 5 daily passages without tetracycline
- 2 daily passages with tetracycline

Cultures were diluted 30,000-fold at each daily passage. The primary analyses use five independent biological replicates for each strain-plasmid condition.

The package contains data for four plasmid backbones:

- p15A
- pBR
- CloDF
- pUC

The main comparisons are:

1. transposase on versus transposase off in matched hosts carrying the chromosomal transposable element;
2. kanamycin maintenance (`+Kan`) versus no kanamycin maintenance (`-Kan`);
3. plasmid copy number (PCN), total transposable-element copy number (TCN), GFP/OD600, and derived response rates.

## Response-rate calculations

The notebook derives loss and gain rates from replicate-level trajectories and plots individual biological replicates. Summary markers show mean ± s.d. Pairwise condition comparisons use Mann-Whitney U tests as implemented in the plotting workflow.

For Figure 5b, mean PCN is calculated within each biological replicate and condition across the corresponding time-course measurements before being paired with that replicate's TCN response rate.

## Reproducibility notes

- Run the notebook from the `experiments/` directory so that relative paths resolve correctly.
- Several later plotting sections use processed CSV files generated by earlier sections.
- The raw instrument files are retained alongside processed tables so that the main qPCR and GFP/OD600 workflows can be traced back to the source measurements.
- Figure assembly, panel lettering, and final layout were performed separately from the numerical processing and plotting steps documented here.
